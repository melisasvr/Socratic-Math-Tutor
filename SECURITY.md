# Security Policy

## Supported Versions
Security fixes are applied to the latest default branch.

## Reporting a Vulnerability
Please do not open a public issue for security vulnerabilities.

Report vulnerabilities privately with:
- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any known mitigations

Preferred contact method:
- Open a private security advisory in GitHub (if enabled), or
- Contact maintainers directly via repository owner contact details.

## Response Targets
- Initial acknowledgment: within 72 hours
- Triage decision: within 7 days
- Fix timeline: depends on severity and complexity

## Disclosure Process
- We will confirm the issue and assess severity.
- We will work on a fix and coordinate release timing.
- We will credit reporters who want attribution.
